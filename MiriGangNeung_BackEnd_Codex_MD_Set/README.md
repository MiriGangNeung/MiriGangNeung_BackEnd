# MiriGangNeung Backend Documentation Pack

Codex가 `MiriGangNeung_BackEnd`를 구현할 때 사용하는 프로젝트 문서 세트.

먼저 `docs/CODEX_START_HERE.md`를 읽는다.

이 패키지는 백엔드 코드 자체가 아니라 **구현을 위한 source-of-truth 문서**다.

`api_manual_guide/original`에는 팀이 제공한 한국관광공사 원본 DOCX를 보존했고,
`api_manual_guide/markdown`에는 Codex 검색 편의를 위한 Markdown 변환본을 포함한다.
