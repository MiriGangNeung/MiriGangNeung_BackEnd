# 01 Project Overview — 미리강릉

## 서비스 정의

미리강릉은 사용자가 가보고 싶은 강릉 관광지를 고르고 자신의 사진을 업로드하면 AI로 해당 관광지를 배경으로 한 여행 미리보기 이미지를 생성하고, 이후 실제 관광공사 데이터를 기반으로 맞춤 여행 코스를 생성하는 데스크톱 웹 서비스다.

핵심은 `AI 이미지 생성 자체`가 목적이 아니라 **AI 미리보기 → 실제 여행 욕구 → 실제 관광 데이터 기반 코스**로 이어지는 흐름이다.

## 서비스 범위

- 지역: 강릉시
- 서비스 유형: 웹
- 회원가입: 없음
- 프론트/백엔드: 별도 repository
- 백엔드: Spring Boot REST API

## 핵심 사용자 경험

1. 마음에 드는 강릉 관광지를 최대 3개 선택한다.
2. 그중 AI 합성에 사용할 원픽을 선택한다.
3. 자신의 사진을 업로드하고 필수 동의 절차를 완료한다.
4. AI 생성 Job의 상태를 확인한다.
5. 생성된 AI 여행 미리보기를 확인한다.
6. 여행 유형/동행/기간 등의 조건을 선택한다.
7. 관광공사 데이터 기반 알고리즘으로 실제 코스를 만든다.
8. Kakao 지도에서 방문 순서와 이동 경로를 확인한다.
9. 코스를 저장/공유하거나 스토리 카드로 확장한다.

## 설계 철학

### 공공데이터 우선

관광지 존재 여부, 위치, 상세 정보 등 사실 데이터는 한국관광공사 OpenAPI를 기준으로 한다.

### AI는 이미지 생성에 집중

코스 추천의 핵심 로직은 현재 LLM에 의존하지 않는다. 재현 가능하고 비용이 낮은 알고리즘을 사용한다.

### 외부 API 격리

한국관광공사/Kakao/AI Provider의 응답 형식이 도메인과 프론트에 직접 전파되지 않도록 Adapter/Client 계층을 둔다.

### 익명 우선

회원 시스템 없이 세션/Job/Course/ShareToken으로 MVP를 운영한다.

## 현재 프론트 기준

프론트 README는 6개 화면의 선형 흐름을 정의하며, 프로덕션 데이터 요구사항으로 `places + photos`, `composite job(create/poll/result URL)`, `course generator(ordered stops/time/stay/crowd/coordinates)`를 명시한다.

현재 프론트의 장소/합성/코스 데이터는 Mock이다. 백엔드가 실제 데이터 계약으로 교체한다.
