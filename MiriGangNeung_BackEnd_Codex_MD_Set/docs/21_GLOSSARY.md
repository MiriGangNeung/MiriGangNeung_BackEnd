# 21 Glossary

## One Pick

사용자가 최대 3개 선택한 관광지 중 AI 이미지 합성의 배경으로 사용하는 하나의 핵심 관광지.

## Picks

사용자가 코스 후보로 선택한 최대 3개의 관광지.

## Composition Job

사용자 사진과 원픽 관광지를 입력받아 AI 합성 작업의 상태/결과를 추적하는 작업 단위.

## Recommendation Engine

관광공사 데이터와 사용자 조건을 이용해 코스 후보를 선택하고 순서를 구성하는 컴포넌트.

## Tour API Client

한국관광공사 OpenAPI와 백엔드 사이의 Adapter.

## Route Client

Kakao route API와 백엔드 사이의 Adapter.

## Share Token

회원 없이 코스를 공유하기 위한 추측하기 어려운 opaque token.

## Temporary Image Storage

원본/생성 이미지를 장기 보관하지 않고 TTL 동안만 보관하는 저장소.

## P0/P1/P2

- P0: 현재 MVP 구현 대상
- P1: 이후 우선 구현
- P2: 장기 확장

## AI Provider

이미지 합성을 실제 수행하는 외부/내부 AI 서비스. 현재 미정.
