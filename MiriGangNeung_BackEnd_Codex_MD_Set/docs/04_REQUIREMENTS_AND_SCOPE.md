# 04 Requirements and Scope

## 중요

기존 공모전 요구사항 정의서는 매우 넓은 범위를 P0로 지정하고 있다. 이 문서에서는 **팀이 현재 확정한 실제 MVP 범위**와 **향후 요구사항**을 분리한다.

원본 요구사항 정의서의 주요 항목에는 AI 이미지 안전성/생성 이력, 여행 코스 생성, 조건 입력, 주변 관광 인프라, 실현 가능한 일정, 지도/이동 경로, 코스 편집/재산정, 대체 장소, 저장/공유 등이 포함된다.

- 관광지 상세

- 실패/재시도
- 안전성/품질 결과를 받을 수 있는 인터페이스
- 생성 이력 metadata
- 다운로드
- 임시 이미지 삭제
- AI 생성임을 명시할 수 있는 metadata

### Course

- 선택 장소 수신
- 원픽 필수 포함
- 여행 유형
- 동행
- 기간
- 후보 장소 필터링
- 추천 점수
- 이동 거리/시간 고려
- 운영시간/휴무일이 제공되는 경우 검증
- Kakao route

- 코스 저장
- 익명 공유
- 삭제/공유 만료

### Redis

- Job 상태
- 임시 데이터 TTL

## 요구사항 충돌 처리

기존 요구사항 정의서에 `여행 날짜, 시작/종료 시간, 출발지, 도착지, 이동수단, 여행 속도, 예산, 반려동물` 등 더 많은 입력이 정의되어 있지만 현재 프론트 UI에는 모두 존재하지 않는다.

따라서 백엔드 P0 API는 **현재 프론트 계약에 맞춘 최소 입력**으로 시작하고, DTO에 미래 확장을 쉽게 할 수 있는 구조를 유지한다.

프론트가 향후 필드를 추가하면 API version을 깨지 않는 optional field로 확장한다.
