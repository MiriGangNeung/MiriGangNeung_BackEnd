# 장소 추천 알고리즘 개선 및 10회 검증 보고서

## 1. 검증 개요

- 검증일: 2026-08-29
- 대상 브랜치: `feat/course-place-preferences`
- 대상 API: 카카오 장소 검색 기반 `/api/v1/courses/{courseId}/nearby-places`
- 추천 범위: 사용자가 고른 관광지 3곳에서 기본 2km 이내, 정확 후보가 부족하면 5km를 거쳐 10km까지 자동 확장
- 검증 방식: 매 회 강릉 관광지 3곳을 시드 기반으로 무작위 선택하고, 프로필별 추천 결과 상위 5개를 평가
- 실험 횟수: 10회
- 실험 데이터: 강릉 관광지 카드 68개와 카카오 장소 검색 결과
- 정리 상태: 실험용 코스 10개와 코스 지점 30개를 모두 삭제하여 운영 데이터에 남기지 않음

10회 라이브 수치는 핵심 점수 로직과 2km 부족 시 5km fallback을 반영한 코드에서 측정했습니다. 이후 문화시설의 겹치는 `related` 키워드를 명시적 불일치로 오인하지 않도록 경계 사례를 추가 보정했고, 5km에서도 정확 후보가 부족한 경우 10km까지 확장하는 fallback을 추가했습니다. 이 후속 변경은 점수·fit 판정이 아니라 검색 공급 범위와 안내 문구를 보완하는 변경이며, 회귀 테스트로 검증했습니다. 아래 라이브 수치에는 10km fallback이 아직 포함되지 않았습니다.

이번 보고서의 `semantic fit`은 선택한 취향과 정확히 일치하거나, 같은 목적의 관련 하위 유형으로 판단되는 후보를 포함합니다. `strict fit`은 선택한 세부 유형과 정확히 일치하는 후보만 계산합니다. 예를 들어 `문화·예술 > 박물관` 프로필에서 `전시관`은 관련 유형으로 semantic fit에는 포함되지만 strict fit에는 포함되지 않습니다.

## 3. 적용한 개선 사항

### 3.1 세부 취향과 카카오 분류의 계층 처리

- 카카오 분류의 부모 경로(`문화,예술`)만으로 세부 취향이 일치했다고 판단하지 않도록 변경했습니다.
- 세부 취향 매칭은 장소명과 최상위 유형을 제외한 카테고리 경로(`중식 > 중국요리`)를 사용합니다.
- 카테고리 전체 경로는 넓은 유형(`자연·산책`, 일반 문화시설 등)을 판단할 때만 보조적으로 사용합니다.
- 주소에 우연히 키워드가 들어간 경우에는 낮은 점수의 address-only match로 처리합니다.

### 3.2 유형별 strong/related 키워드

- `식도락`: 한식·중식·일식·양식의 정확 키워드를 우선합니다.
- `휴식 > 커피·로스터리`: `커피`, `로스터리`, `카페` 계열을 활용하되, 단순히 부모 카테고리 `카페`만 있는 경우를 과대평가하지 않습니다.
- `휴식 > 디저트·베이커리`: 디저트·베이커리 계열을 정확 유형으로 취급합니다.
- `문화·예술 > 전시`: 전시관·전시장·전시회·미술관·아트센터·갤러리·공연을 strong, 박물관·기념관을 related로 취급합니다.
- `문화·예술 > 박물관`: 박물관·기념관을 strong, 전시·미술관·갤러리를 related로 취급합니다.
- `자연·산책`: 해변·해수욕장·공원·수목원·계곡·폭포·전망대 등 자연 탐방 키워드를 활용합니다.
- 자연 추천에서 자전거 인증센터·레저·스포츠·테마파크·수영장처럼 목적이 다른 후보는 제외 키워드로 감점합니다.

### 3.3 점수 가중치와 불일치 방어

- 정확한 세부 취향 일치: 55점
- 관련 세부 취향 일치: 42점
- 주소에서만 확인된 세부 취향: 44점
- 넓은 유형 일치: 32점
- 세부 취향을 선택했지만 일치 여부를 확인할 수 없거나 다른 음식 분류인 후보: 20점
- 카테고리만 일치: 8점
- 거리: 20점
- 동행 유형: 10점
- 장소 정보 완성도: 10점
- 프랜차이즈 감점: 최대 8점
- 세부 취향이 명시적으로 다른 후보도 제외하지 않고 20점의 중립 점수로 유지

선택한 세부 취향과 정확히 일치하는 후보만 55점으로 우선합니다. 다른 음식 분류나 카카오 분류만으로 음식 종류를 확인할 수 없는 후보는 모두 20점의 중립 구간에서 거리·동행·정보 완성도로 경쟁하므로, 중식을 골라도 다른 후보가 사라지지 않고 특정 미확인 분류가 과하게 유리해지지 않습니다.

### 3.4 설명 문구 개선

명시적으로 다른 유형인 후보에는 `선택한 세부 취향과 다른 분류지만 함께 보여드려요`를 표시합니다. 카카오 분류가 불충분한 후보에는 `세부 취향을 확인할 수 없어 일반 후보로 함께 보여드려요`를 표시하여, 중립 점수를 식도락 취향 일치로 오해하지 않도록 했습니다.

### 3.5 정확 후보 부족 시 5km 자동 fallback

- 먼저 기존 설정 반경인 2km에서 카카오 장소를 조회합니다.
- 서버가 카카오 장소명과 카테고리 leaf를 기준으로 정확한 세부 취향 후보 수를 계산합니다.
- 정확 후보가 3개 미만일 때만 같은 관광지 기준으로 5km를 추가 조회합니다.
- 5km 결과는 카카오 장소 ID로 중복 제거한 뒤 기존 2km 결과와 합칩니다.
- 5km 조회로 새로 들어온 후보에는 `주변에 조건에 맞는 장소가 적어 5km까지 검색했어요`라는 이유를 붙입니다.
- 정확 후보가 3개 이상이면 5km API를 호출하지 않아 불필요한 외부 호출을 줄입니다.

### 3.6 5km에서도 정확 후보가 부족할 때 10km fallback

- 5km까지 조회한 뒤에도 정확한 세부 취향 후보가 3개 미만이면 같은 관광지 기준으로 10km를 추가 조회합니다.
- 10km 결과도 카카오 장소 ID로 중복 제거하고 기존 후보와 합칩니다.
- 10km 조회로 새로 들어온 후보에는 `주변에 조건에 맞는 장소가 적어 10km까지 검색했어요`라는 이유를 붙여 사용자가 검색 범위를 알 수 있게 합니다.
- 2km 또는 5km에서 이미 확보한 후보가 10km 후보 때문에 불필요하게 10km 안내로 바뀌지 않도록, 후보가 처음 발견된 확장 단계의 안내를 유지합니다.
- 5km에서 정확 후보가 3개 이상이면 10km API를 호출하지 않습니다.

중식·양식 실험은 5km fallback을 수행해 후보 수는 늘었지만, 정확한 후보 자체가 적어 semantic fit은 각각 20%로 유지됐습니다. 두 경우 모두 정확한 후보가 상위 1위로 올라갔습니다. 즉, 이번 fallback은 “조건에 맞는 장소를 더 넓은 범위에서 찾는” 문제는 보완하지만, 강릉 전체 데이터에 해당 유형이 부족한 문제까지 해결하지는 않습니다.

## 6. 결론 및 다음 개선 후보

이번 변경으로 다음 동작은 확인되었습니다.

1. 세부 취향 키워드가 거리보다 충분히 큰 영향력을 가집니다.
2. 카테고리 부모값만 우연히 일치하는 오추천을 줄였습니다.
3. 자연 추천에서 자전거·레저·수영장 등 목적이 다른 후보를 상위에 올리는 문제를 억제했습니다.
4. 세부 취향이 다른 후보는 이유 문구와 점수가 일치하도록 바뀌었습니다.
5. 문화시설은 exact 후보가 적을 때 관련 문화시설로 자연스럽게 보완됩니다.
6. 정확 후보가 부족한 일식·중식·양식 회차에는 5km fallback이 자동으로 작동했습니다.
7. 이후 5km에서도 정확 후보가 부족한 경우 10km까지 추가 확장하고, 확장 단계가 후보 추천 이유에 표시되도록 보완했습니다. 이 10km 단계는 아래 10회 라이브 수치에는 포함되지 않았으며 단위 테스트로 동작을 검증했습니다.

후속으로 가장 효과가 큰 작업은 다음과 같습니다.

- 중식·양식처럼 5km까지 넓혀도 정확 후보가 적은 경우, `강릉 전체 검색`과 연결해 더 넓은 범위의 정확 후보를 보여주는 정책 검토
- 디저트·다방처럼 카카오 분류가 넓은 후보에 대한 추가 alias와 제외 키워드 보강
- 실제 사용자 클릭·추가·삭제 로그를 수집한 뒤, 현재 키워드 평가와 별도로 온라인 선호도 지표 추가
